# 🌙 Ramadan 2026 – Timetable & Dua Web App

A simple and elegant Ramadan 2026 web application that displays:

* 📅 Current Date
* 🕒 Live Time
* 🗓️ Ramadan 2026 Information
* 🤲 Essential Ramadan Duas
* 📋 Ramadan Timetable View

This app focuses on a clean Islamic design with easy navigation between **Time Table** and **Dua** sections.

---

## 📸 Overview

The home screen displays:

* Ramadan 2026 title
* Current day and date
* Live running clock
* Two main action buttons:

  * **Time Table**
  * **Dua**

The UI is minimal, responsive, and lightweight.

## 🚀 Features

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/ramadan-2026.git
cd ramadan-2026
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run development server

```bash
npm run dev
```

The app will run on:

```
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```
